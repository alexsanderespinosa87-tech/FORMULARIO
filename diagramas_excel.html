Descripción
Como Recepcionista de AnimalCare, quiero interactuar con el Sistema de Gestión Veterinaria para ejecutar los procesos de programación de citas y registro de consultas, para garantizar un flujo de atención ordenado y eficiente tanto para el equipo médico como para los clientes.

Flujo detallado de interacción:
1. Consulta y Validación: El sistema debe permitirme visualizar la "Agenda" global para identificar disponibilidades. Previo a cualquier registro, el sistema debe exigirme consultar la "Lista de pacientes"; si el paciente no existe en la base de datos, el sistema debe bloquear el agendamiento hasta que se realice el registro correspondiente.

2. Registro de Transacción: Una vez validado el paciente, ingresaré los detalles (fecha, hora, motivo). El sistema debe diferenciar entre "Programa citas" (para eventos futuros que disparan recordatorios) y "Registra consultas" (para pacientes que llegan físicamente a la clínica en ese momento).

3. Disparadores: Al guardar exitosamente, el sistema debe actualizar automáticamente la base de datos central, reflejar el cambio en los reportes del Veterinario y activar el conector con el Servicio de Email.
Observación (Flujos del Diagrama)
  • Entradas del Sistema: La funcionalidad depende estrictamente de recibir la "Lista de pacientes" y la visualización de la "Agenda" desde el Sistema de Gestión Veterinaria.
  • Salidas del Actor: La Recepcionista ejecuta dos acciones principales hacia el sistema: "Programa citas" (para futuros eventos) y "Registra consultas" (para la gestión del momento o llegada).
  • Coherencia de Datos: No se puede registrar una consulta sin validar primero la existencia del paciente en la lista proporcionada por el sistema.
  • Integración: Estos flujos desencadenan procesos posteriores hacia el Veterinario ("Citas del día") y Servicio de Email.
Nota de Diagrama: Los datos de interacción y dependencias corresponden exactamente a las flechas de entrada y salida de la entidad Recepcionista en el diagrama de contexto.
